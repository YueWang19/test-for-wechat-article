# Chrome vCaptions 字幕回退

当 yt-dlp 没有拿到可用的英文字幕时，优先尝试用户 Chrome 中已安装的 **vCaptions – Video Caption List**（用户可能称 V Caption），再请求手动提供字幕。扩展不是保证成功的转录服务；若视频本身没有可取得的字幕，也可能失败。

## 获取与复制

1. 使用浏览器工具在 **Chrome** 打开当前 YouTube URL，确认视频 ID、标题与时长。复用同一视频的已打开标签页。内置浏览器通常不能使用 Chrome 扩展。
2. 查看工具栏的 vCaptions 扩展，点击打开 Captions 面板。页面工具无法操作扩展工具栏时，使用允许的原生 Chrome UI 自动化。不得通过读取扩展私有存储、浏览器账号或 cookies 来绕过 UI。
3. 在当前界面选择原始英文字幕，仍优先人工英文、其次自动英文。实际类型不明时记为 unknown，不因为来自扩展就标成人工字幕。
4. 查看全文字幕/Transcripts（有些版本显示 TS）及 Copy/复制或 Download/导出操作；先观察当前控件，不能把固定坐标或某版本标签写成通用选择器。复制**全文原始英文字幕**，不是摘要、翻译、Chat 或 Refine 生成的文字。若只显示当前句或部分可见行，不能当作完整转录。
5. 若 Copy 报失败，可打开 Download / Download Center，选择全文 Transcripts 的 TXT/MD 导出并核验下载文件；有时间戳需求且界面支持时可选 SRT/VTT。保留导出原件，工作副本只移除已确认的标题、URL 元信息和扩展水印，不改写字幕正文。点击明确的复制控件后才读取本次复制结果；只读所需的文本，不读取用户无关剪贴板历史。浏览器工具不支持剪贴板读取时，使用界面提供的文件导出，或请用户手动复制并粘贴/上传。不要用截图 OCR 或自行补句冒充原始字幕。
6. 保存 `captions-vcaptions-raw.txt` 原始结果和 `transcript.txt` 工作副本。保留真实时间戳；复制内容没有时间戳时不编造。已有 yt-dlp 转录时，单独保存扩展结果用于比较，不覆盖来源。
7. 保存 `transcript-source.json`：video_url、video_id、title、duration_seconds（已知时）、method=`chrome-vcaptions`、language、caption_type（human/automatic/unknown）、timestamps_present、copied_at、coverage_notes。无法从扩展验证的元数据记为未知，不猜测。

## 验证与停止条件

核对字幕开头和末尾、英文正文及与时长的覆盖关系；检查是否混入界面文字、摘要、其他视频内容或只有部分字幕。记录缺口。即使成功复制，也不能仅凭非空剪贴板断言全文完整。

面板持续 Loading 时，做一次有理由的恢复（例如重新打开当前视频的面板，或观察到字幕语言可用后重新选择英文）。仍失败则停止扩展尝试，报告可见错误/加载状态，请用户在 Chrome 手动复制或导出；不要循环刷新、安装其他扩展或付费开通。安装/权限变更不包含在普通使用既有扩展的授权中。

仅成功取得并验证可用转录后继续中文编辑。两条路径都失败时保留诊断，停止生成文章，绝不根据简介或标题编造正文。

## 手动回退话术

“请在 Chrome 打开该视频，点击 vCaptions，选择英文，进入全文字幕模式，使用复制全文或导出功能，然后把字幕粘贴到聊天中或上传文件。请保留时间戳（若有），并说明字幕是否为自动生成。”
